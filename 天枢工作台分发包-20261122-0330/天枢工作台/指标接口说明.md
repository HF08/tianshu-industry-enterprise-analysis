# 财务计算与行业状况内核

## 原始披露补查

行业按截止日查询国家统计局已登记的2024、2025年度及2026年前三季度表3，匹配行业全称；动力电池使用电气机械大类作参照。动力电池专属归档含工信部公报、创新联盟署名月报、国家标准以及研报发布方自己的价格调查。source-snapshot.json 保存核验后的指标与定位，并区分报告快照和联网接口。不是所有行业都配置了协会原表，其他行业可补充研报包。

企业按代码或证券简称查询巨潮证券主体、公告目录和最近五年年度报告全文，按“前五名客户／供应商”表名与单位定位。联网 PDF 提取需要 PATH 中的 pdftotext（Poppler 或兼容版本）；未安装时可保留公告定位、已归档观测和结构化财报，台账记录缺失原因。宁德时代2024、2025年年报另归档了经人工定位的产销存和附注，仅对该主体生效。随包实跑台账可以按指标输入号追溯页码。

**研报提取入口。** 点击会话输入框左侧“＋”，载入下列 JSON。text 放入所需页的真实文字，保留表头、年份、单位和行名。模型按原文抽取历史实绩，程序校验摘录、定位、数值、单位与年份，按原报表口径保存。转引、预测、身份未外部验证的自报材料须在报告中说明；必要时用出版方原表替换。导入后在下一轮匹配的 FIN / IND 派单时调用当前配置的模型。该入口处理文字，扫描件需先核对文字层。

```json
{"type":"report","role":"IND","target":"中国动力电池行业","publisher":"原报告署名机构","source":"https://example.org/original-report","published":"2026-04-30","text":"在此粘贴完整表名、统计范围、期间、原文、单位与页码"}
```

输入企业代码、证券简称或行业名称。天枢派发 FIN / IND 时调用本地 POST /api/kernel。当前版本针对境内 A 股、人民币合并报表及中国行业。内核返回原始观测、输入编号、公式、指标结果、冲突和缺项，按快照留存。取数不使用模型 API Key。

## 补录与字段

在输入框左侧点“＋”选择 UTF-8 JSON 数组。同一会话再次导入将替换先前资料包。每条记录包含 target（与派单标的一致）、role（FIN 或 IND）、year、field、value、unit、source、locator、published，可加 dimension、publisher、sector。金额填写人民币元、万元或亿元；件数、重量、面积及时间等必须先统一口径。价格与单位产品耗料应换算到相同原料和产品计量基础。按规格不同的产品分别填 dimension，不能混用数量单位。全市场份额须列全体企业的百分数，不能将“其他企业合计”当作一家。年度变更事项可传原文摘要字符串。以下仅说明格式，数值为演示：

```json
[{"role":"IND","target":"测试行业","year":2025,"field":"完整市场份额","value":[40,35,25],"unit":"%","dimension":"国内终端销量","source":"示范统计表","locator":"表1","published":"2026-03-01"}]
```

《指标字段字典.json》按企业、行业及八个行业模板列出公式、单位及必需输入字段。“前”表示上年同口径，“三年前”表示前三年；“前五客户销售额”是当期前五客户合计。期末和平均数按公式取值。市场份额集中度另由完整份额数组生成，HHI 采用 0–10000 刻度。杜邦三项分别为归母净利率、资产周转率、权益乘数，三者乘积对应平均归母权益 ROE。

**附注与专门披露的取数口径**

- 有息负债采用附注统一口径，包含租赁时相应调整短债和现金口径。一年内到期非流动负债可能含非有息项目，不能直接当短期有息负债。到期结构、担保、表外义务须带期限或说明。
- 税后经营利润可由披露的净口径补录，或按台账的有效税率近似。投入资本可由权益、有息负债及现金等价物推算。折旧摊销须为当期完整合计；缺失组成不得默认为零。经营营运资本默认采用交易性科目代理。标准定义与披露调整值冲突时保留差异。
- 净营运资本、增量 ROIC、DPO、速动比率、再投资率和经营现金流付息倍数的具体分子分母见字段字典。经营现金流付息倍数的分母采用利息费用，DPO 的分母采用营业成本代理。
- 订单、指引和实际完成需限定同一业务及时间范围。量价贡献分解仅适用于同一产品、币种、单位与收入确认范围；切换产品组合要分产品后汇总。经营现金流与利润并列使用五年序列。
- 银行与保险采用专用模板，通用资本效率指标停止计算；监管口径优先。保险准备金充足性、医药管线和专利窗口、医保覆盖、政策和审计事项以披露原文为依据。峰值销售须注明预测主体及假设。

## 本地调用

### 角色计算与共用台账

每轮只拉取一次企业或行业台账。BIZ 按产品计算毛利额并结合产品收入占比和分部趋势；COMP 按同分类上市公司的年度合并营业总收入，计算候选企业与标的的营收倍数，按对数规模距离选出最多三家。两家企业的规模相近只支持候选筛选。RC、RI 接收同组前三份回报并核对年度变化、反证及资料缺口。

CHAIN、COMP 可以读取资料包的“产业链关系”，其 value 填对象，例如 {"from":"甲公司","to":"乙公司","type":"供货"}。只有真实披露支持的关系才能用于报告。CHAIN 的关键投入采购占比需要同期间同环节的“关键投入采购额”和“同范围采购总额”。DEM 的需求渗透率需要“已采用客户数”和“可比客户总数”；客群及可及市场占比分别使用“客群销售额”“可及市场销售额”，分母为“同范围市场销售额”。分子与分母的 dimension、期间与计量单位必须一致。资料包的 role 可填上述任一研究或风险角色。

共享内核默认返回 JSON。界面发送 Accept: application/x-ndjson 时返回逐行事件，progress 携带实际取数或计算操作，result 携带最终台账，error 携带失败原因。

同源 POST /api/kernel，JSON 请求体含 role、target、as_of（ISO 时间）、sector（可选）、records（可选）。返回 years、sources、observations、interim、metrics、missing、conflicts、issues。每个指标用 year、dimension、name 定位，inputs 引用观测 id；中间计算可继续回溯。纯披露类记录直接引用原始字段。跨期增长、分母、数据源状态和口径冲突单独检查。网络失败可使用已导入的原文数据继续。
