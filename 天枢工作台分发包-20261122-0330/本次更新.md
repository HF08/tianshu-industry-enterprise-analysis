# 产业链分析版本

解压后运行「天枢工作台/START.cmd」。企业和行业两个模式都派发四个平级研究角色：原有三个研究角色，加上「产业链分析」。各角色共用一轮取数，产业链角色同时接单并等待所需的公共台账，不等待财务或行业研究回报。四份研究回报随后交风险复核，最后由报告代理汇编。

- 研究全览：中央保留研究标的和一个「产业链分析」入口。点击产业链入口可在同一页看上游、中游和下游。四角保留原专业研究及风险卡，报告代理不占全览卡片。
- 研究分册：包括产业链分析和其他研究、风险角色；可视化报告没有独立分册。顶栏「展开报告」仍可进入本轮生成的报告。
- 报告：沿用原上下游关系区，呈现产业链代理的模式筛选、产业活动、关系与证据。可按关系类型筛选，点击节点或相邻关系查看说明，企业模式高亮标的所在环节。单轮资料不足时保留缺口。
- 提示词：industry-chain-agent.md 保存附件的双模式完整规范，server.mjs 仅对该角色加载，竞争角色继续独立分析同业。互证请求随角色结果交接。
- 布局：桌面左侧会话列表加宽，尤其是调查导图打开时；窄屏保留原有自适应。
- 随包已有的两份 DeepSeek HTML 报告和旧实录为此前留档。打开实时工作台运行新调查，才能生成本次增加产业链角色后的新报告。
- 验证：Chrome 浏览器分别以企业、行业真实留档数据和模拟 Responses 服务检查四角色调度、风险接收四份交接、研究分册过滤、全览合并及报告图谱渲染。此次未重新付费调用模型验证产业链报告内容质量。
研究全览四张成果卡现以主要判断为大标题，以对应期间、指标与数据口径为小字。历史实录没有新卡片字段时从该角色既有回报提取；证据不足会显示限制。
全览四张成果卡进入分册后，判断、支撑数据和研究说明直接呈现；来源及计算记录保留原折叠入口。工作与全览模式切换键增加一体式底框。
