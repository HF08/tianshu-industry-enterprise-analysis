# 天枢 · 新构建版本交付及验收

## 直接使用

先完整解压。离线查看本轮真实输出可打开根目录的「美的集团-实跑报告.html」或「中国动力电池行业-实跑报告.html」。两份正文、数字、图表及源记录已嵌入 HTML。外部资料原文需网络。报告内可悬停、右击、逐级查看依据及选择引用；在实时工作台可以继续提问与更新。

要发起新调查，在 Windows 与 Node.js 22+ 环境双击「天枢工作台/START.cmd」。在设置中选 DeepSeek 官方、填写自己的密钥并获取模型列表，模型选 deepseek-flash。也可使用原有本地 Responses 反代和该反代提供的模型 ID。当前版本的请求协议为 /responses。原「实机演示.html」仍是随审查包交来的 dfmodel 录制回放，展示原版调查；两个新报告来自本轮 DeepSeek 联测。

## 分工与报告入口

天枢确定研究对象和范围。企业分支由财务计算、产品与商业模式、同行竞争分析先工作，企业风险随后复核。行业分支由行业状况、同业企业竞争分析、规模客户先工作，行业风险随后复核。第五个角色 RPT 接收本轮四份回报及带来源的指标目录，撰写结论、反证与风险。天枢负责对话总结。原多线调查导图、实况、全览及分册保留。COMP/CHAIN 的提示词已分别转向企业同比与可比公司、行业企业样本排名与集中度分析；产业链仍是报告中的独立证据视图。

报告生成后使用顶栏「展开报告」。先读正文。句中浅色虚线表示可查证据：悬停看摘要和适用公式，跨期差额显示两期原值及减法；右击打开「引用／查看来源」，手机轻点或键盘选择也可操作。查看输入字段、来源链接、发布日期与页表；PDF 有页码时跳到对应页。引用添加到会话输入框并携带快照、数值、公式及来源。同一会话的「更新报告」重新取数并保留旧版；不同会话的引用及版本相互隔离。资料不足时报告显示范围、缺项、冲突和接口错误。刷新实时工作台会清除页面内存会话。

## 左栏与最高档

波形统计最近30秒实际收到的文本/推理增量字符数。无逐块 token 数时显示字符/s；请求完成后依据 response.completed.usage 的输出 tokens 与端到端耗时显示 tok/s。总用量按会话累计，重试计入实际消耗；缓存命中率为已上报缓存输入 tokens / 对应输入 tokens，未知用量留空。上下文据已知模型窗口估算；不能确认的窗口不显示百分比。

新构建原有兼容映射会把最高档存为 xhigh。对官方 DeepSeek，现将旧配置 xhigh 归一为官方最高 max，并将展示名 DeepSeek-V4.1-Flash-1017 归一为 deepseek-flash；自定义反代保留原命名及档位约定。软件不能替账户开通模型权限或修复另一台电脑的网络。检查时以实际响应状态、模型 ID 和 reasoning.effort 为准。

## 对赛题逐项核验

| 要求 | 本轮实际验收 |
|---|---|
| 多智能体协作 | DeepSeek 官方真实 Responses 流分别完成企业和行业任务；每组4个研究/风险角色和1个报告角色均完成 |
| 资料与核验 | 企业最终台账301条年度结果、58条近期观测；行业54条年度结果、36条近期观测。每条报告判断校验引用编号；年报、公报、协会原表和平台转录分别保留来源 |
| 经营与风险 | 美的集团2025年归母净利润增长、经营现金流下降；正文对比五年序列并区分归母利润和现金利润比的合并净利润分母。同行规模不能替代同业现金流质量判断 |
| 竞争与产业链 | 比较海尔智家、格力电器、海信家电的合并营收相对倍数；动力电池报告按上市样本营收集中度比较企业，另列国内装车和含出口的销量。产业链优先采用本轮有证据的图谱；缺图时用真实环节观测或关系条目 |
| 溯源、追问、更新 | 浏览器真实流程已核对句内悬浮、右键来源、引用后发送追问；美的集团更新后有两个独立版本并展示变更比较。两个离线报告另通过 Chrome 打开与来源跳转测试 |
| 监测与兼容 | 经本地服务发送旧最高档配置及展示名，官方返回 model=deepseek-flash、reasoning.effort=max。真实 usage 提供输入、输出、缓存数量，左右两组并发会话各自显示吞吐和命中率 |

证据存在不等于推断必然成立。行业销量与装车量的差额不能直接等于出口或库存；跨行业样本的上市企业营收份额不能替代装车市场份额。当期缺失完整企业份额、同行利润或现金流序列时需保留缺口。运行环境、修订数据及第三方限流会影响下次报告。实跑报告来自普通研究档位；最高档单独经过真实请求验证，未将完整五角色任务全部按最高档再执行。
