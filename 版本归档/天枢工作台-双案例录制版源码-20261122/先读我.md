# 天枢工作台 · 双案例录制版

**企业样本**　双击 `美的集团-实跑报告.html`，在「经营表现」切换指标，点数据查看来源或复制引用，再在右上角导出报告。

**行业样本**　双击 `实机演示.html`，观察动力电池调查回放，点击「跳到汇总」进入角色分册。双击 `中国动力电池行业-实跑报告.html` 审阅结果；在经营表现的销量柱条上点「查看来源」，可打开随包 PDF 第 7 页。

**启动在线工作台**　安装 Node.js 22 或更新版本，双击 `天枢工作台/START.cmd`。在设置中保存 Responses 服务地址、模型名及所需凭证。在线调查依赖模型和数据源，格式错误会重试并显示原因。离线报告和回放可直接打开。

**继续追问历史案例**　在已配置模型的在线工作台点击输入框左下角的「+」，选择 `案例/美的集团-实跑报告.json` 或 `案例/中国动力电池行业-实跑报告.json`。打开指标的来源并点击「引用并追问」，发送问题后可收起报告，在主会话阅读真实回复。报告顶部可直接下载 Markdown 或 PDF。离线打开 HTML 时，PDF 使用系统打印窗口另存。

**从源码重建**　用 Python 3 分别运行 `演示工具/生成演示.py` 和 `演示工具/生成报告.py`。报告原始数据保存在 `案例/*-实跑报告.json`，带来源的历史实录、PDF 和界面组件均随包提供。

**本次修复**　修复了旧版共用的模型回报接收和解析，区分空回报、未闭合、语法与字段错误。恢复报告中的近期指标，分组显示年度和近期口径。修复在线 PDF 导出时浏览器写入尚未结束就报错的问题，报告留档保留原模型登记信息。修复离线报告横条遮挡、离线引用、全屏重绘和小屏会话入口。
