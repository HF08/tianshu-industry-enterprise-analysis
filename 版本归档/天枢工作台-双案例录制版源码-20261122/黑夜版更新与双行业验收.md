# 黑夜版 · 报告阅读与双行业研究

解压后双击「天枢工作台/START.cmd」启动，需 Node.js 22+。实时调查由使用者自行配置模型；包内不带 API 密钥。两份新生成的行业报告可直接用浏览器打开。

## 已修复

- 打开研究报告时，输入框始终保留在会话中的原位置；报告独占接近整个浏览器视口，正文区域独立滚动。批量引用后可关闭报告继续输入，也可在来源详情点击「引用并追问」直接回到原输入框。
- 报告和产业链分册共用同一关系图。指针接触箭头连线时，起点与终点同时亮框，线上附近显示“起点 → 终点、关系类型、证据标记”。虚线配置了加宽的透明命中区。键盘聚焦和触屏点击可查看同一关系说明。
- 行业名称在应用数据层归类；锂电、锂离子电池、动力电池等按电池样本检索，光伏、光伏发电、光伏组件等按光伏设备样本检索。全产业、子市场、上位规上行业与上市分类样本分别保留维度。

## 推荐现场考察的问题

**中国动力电池：2025年企业销量与国内装车量是否同步增长？** 2024→2025年，含出口的生产商销量由791.3升至1200.9 GWh，增幅约51.8%；国内装车由548.4升至769.7 GWh，增幅约40.4%。二者都增长，销量增速更高。两个统计量的差额不能直接认成出口、渠道压货或库存。动力电池的数值不能代表所有锂离子电池。[协会署名月报，第7、19页](https://www.jtcopper.com/wp-content/uploads/2026/04/2026%E5%B9%B43%E6%9C%88%E5%8A%A8%E5%8A%9B%E7%94%B5%E6%B1%A0%E6%9C%88%E5%BA%A6%E4%BF%A1%E6%81%AF.pdf)

**中国光伏发电：2025年新增装机的增长主要来自哪种建设形式？** 全国新增约317 GW，上年约278 GW；集中式164 GW，同比约多5 GW，分布式153 GW，同比约多35 GW。按两年公报的舍入值比较，新增规模的增长主要来自分布式。2025年全国光伏发电量约1170 TWh，上年834.1 TWh。两项分别衡量装机功率与发电量；总发电量未按建设形式拆开，不能据此认定分布式贡献了多少发电增量。2024年分项之和与合计有舍入差。[国家能源局2024年](https://www.nea.gov.cn/20250221/e10f363cabe3458aaf78ba4558970054/c.html) · [2025年](https://www.nea.gov.cn/20260212/742b8c6a078347b0b39de676c05c5d58/c.html)

sector-data.mjs 读取国家能源局年度及2026年前三季度运行通报、工信部锂电分用途产量、中国政府网光伏分环节制造数据，连同原有协会快照、统计局、Comtrade及上市样本输入共享台账。网页未匹配或访问失败时记录原因。报告按实际来源时间展示，不承诺覆盖全部历史年份或实时行情。价格价差、专属市场销售额、企业利用率、库存、利润归因等缺乏同口径资料时保留待核实。数据源随时间修订，重新运行的覆盖可能变化。
最终端到端核验：在 Chrome 使用 DeepSeek 官方 Responses API，分别运行“中国动力电池行业”和“中国光伏发电行业”。两轮的四个并行研究角色、风险角色及报告角色均已交卷。报告弹窗实测占视口高度95.9%、宽度96.9%，输入框仍在弹窗外。两轮均检测到悬停有向关系时恰有两个端点亮框；另在两份导出报告中验证箭头旁关系标签、指标右击及来源链接。
