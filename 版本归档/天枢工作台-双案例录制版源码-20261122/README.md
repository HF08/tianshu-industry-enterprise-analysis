# 天枢 · 行业研究与企业经营分析助手（报告与导图合并版）

## 本版是什么

- 基线：队友的「Sidebar / 原配色恢复版」交接包。
- 本版继续开发：报告弹窗按预览样式重写、报告支持 Markdown 与 PDF 下载、左下角模型状态栏重做、设置改为「模型 / 模式」侧边导航、恢复右侧交互调查导图、修复产业链分析回报校验。
- 运行代码在 `天枢工作台/`；案例、演示工具、实跑报告沿用原包。

## 启动与配置

1. 安装 Node.js 22 或更新版本。双击 `天枢工作台/START.cmd`，或在该目录运行 `node server.mjs`。
2. 默认地址 `http://127.0.0.1:18721`；端口被占用时服务会自动顺延，以窗口打印的地址为准。
3. 浏览器打开后点右上角齿轮：在「模型」页配置服务商、接口地址、API Key、模型名称；「模式」页可选择默认、企业、投资、经济四种模式。
4. 模型配置保存在浏览器 localStorage（键 `tianshu.day.user-config`），包内不带任何 API Key。
5. 演示与案例：`实机演示.html` 可不联网回放；三份实跑报告 HTML 可直接打开。

## 本版改动

### 报告弹窗

- 五节 01–05：摘要、经营表现、财务质量、风险清单、对授信的含义；经营表现与财务质量各 4 张指标卡，风险卡与授信结论卡按预览样式。
- 弹窗居中、带遮罩与升起动效；标题在上、副标题在下；数据点悬浮显示来源、公式与证据链，单击可引用或查看来源。
- 报告底部不再显示追问回复，追问回复只出现在主界面会话。
- 证据导航（依据 / 数据来源 / 全部端口）已移除。

经营表现内可切换年度趋势与产品结构，查看竞争对比和产业链。数据点沿用报告原有的来源与引用菜单。三份随包实跑报告共用新版报告组件，可离线查看。

### 报告下载

- 报告头部右上角两个按钮：「下载 Markdown」「下载 PDF」，随报告打开状态显示。
- 两种格式共用同一份文档模型：五节正文 + 附录 A 数据与计算明细、附录 B 来源清单、附录 C 缺口与核验；正文带 [n] 引用编号。
- Markdown 直接下载 `.md` 文件；PDF 由服务端调用本机 Edge 无头模式生成 A4 文档（页眉、页脚、页码），失败时退回浏览器打印窗口。
- 服务端接口 `POST /api/report-pdf` 不引入新依赖；需要本机安装 Edge 或 Chrome。

### 左下角模型状态栏

- 模型行（模型名 + 本次运行 / 下次运行）、速率与 60 秒波峰图、Tokens、缓存命中、上下文四档色条。
- 用量解析同时兼容 Responses 与 Chat Completions 两种字段；个别请求拿不到用量时按接收字符估算并在数值前标 `≈`。

### 设置

- 左侧导航分为「模型」与「模式」两页。
- 模式页说明文字「选择合适模式以调整研究侧重、智能体任务与编排」，提供默认、企业、投资、经济四项及一句说明，底部为虚线圆角框「导入或与天枢一起构建你需要的模式」。
- 模式选择目前只改界面状态，不改变研究流程与智能体编排。

### 其他

- 调查期间中央保留会话输出，右侧导图按实际进度展开。可折叠分支、查看来源或进入全览。原有角色面板仍可单独打开。
- 报告打开时输入框 3 秒无编辑会自动收起半截；打字、引用、上传等编辑动作立即展开；关闭报告后不再收起。
- 产业链分析：`industry-chain-agent.md` 补充 `evidence_pack` 引用规则与模块校验约束，修复回报连续三次校验失败的问题。

## 已知限制

- 模式选项是界面演示，尚未接入研究编排。
- PDF 生成依赖本机 Edge 或 Chrome；无浏览器时只能走打印另存。
- 模型需使用者自行配置，包内无 API Key。
- 会话与运行记录保存在页面内存，刷新会丢失。
- 真实数据缺少某些指标时，报告用可用指标补齐，并保留待核实缺口，不编造数字。
