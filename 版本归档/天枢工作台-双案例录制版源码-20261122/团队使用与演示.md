# 天枢多线调查工作台 · 团队使用与演示

先把 ZIP 完整解压到普通文件夹。给评委展示时，双击根目录的 `实机演示.html`，用 Edge 或 Chrome 打开。它会自动播放，约 36 秒走完这次动力电池调查。播放、拖动进度和查看随案 PDF 都可离线使用。

## 一分钟怎么讲

| 操作 | 可以这样讲 |
| --- | --- |
| 打开演示，等右侧出现三条彩色分支。 | “这次要查的是，中国动力电池企业卖出了多少，国内汽车实际装上了多少。中间是会话现场，右边三个小组同时查行业数据、上下游和客户需求。” |
| 点底部「暂停」。在右图点一个已出现的取证或发现节点，再点分支标题收起、展开。 | “每条线有自己的进度。点开可以看这一步取得的依据。” 点「播放」继续，或拖动进度条复看。 |

这次实跑由本地 `dfmodel` 完成，用时 2 分 36 秒。记录里有 30 个进度事件、11 段按接收时间合并的公开文字和 4 份角色回报。四组都提交了结果，并分别登记了待补证项。播放时压缩了等待时间。协会原件随包提供，其余来源的外部网页需要联网。

## 在另一台电脑上跑新会话

1. 在 Windows 上准备 Node.js 22 或更高版本，并启动本机支持 Responses 流式输出的模型反代。`127.0.0.1` 指当前演示电脑。这份包自带工作台，反代需要由团队另行提供。
2. 双击 `天枢工作台/START.cmd`。浏览器会打开工作台，运行期间保持命令窗口打开。默认地址是 `http://127.0.0.1:18721`，端口被占用时，以窗口打印的地址为准。
3. 点右上角齿轮，基础地址填 `http://127.0.0.1:7891/v1`，模型 ID 填 `dfmodel`，保存。本次测试使用的本地反代允许密钥留空。
4. 在中央输入框发送下方的问题。工作台会随实际派单、角色指引装载、公开回报和汇总更新右侧导图。若已折叠侧栏，点「调查导图」打开。结束后关闭启动窗口即可停止本地服务。

> 调查中国动力电池行业。请分别核对 2023—2025 年中国电池企业的动力电池销量（含出口、储能单列）和国内新能源汽车动力电池装车量。从行业趋势、上下游和客户需求三条线取证，交给风险组复核。哪些年份能列出差额？已有证据能说明差额的去向吗？请附原始出处和页码。

包中 `案例/动力电池实录.json` 的 `question` 字段保存了实跑原题。每轮新调查使用当时可取得的资料和模型返回，节点到达时间、措辞和取数结果会随之变化。

## 审查和修改从哪里开始

| 要改的部分 | 入口 |
| --- | --- |
| 共用的分支、连线、展开动作、调查全览和来源详情 | `天枢工作台/app/research-board.js` |

| 离线页面、导图样式和播放节奏 | `演示工具/player.html`、同目录的 CSS、`case-player.js` |

改实时前端后，刷新本地工作台即可查看。要让改动后的共用导图或离线播放器出现在单文件 HTML 中，在解压后的根目录打开终端，运行下方命令。重建需要 Python 3，仅用标准库，无需联网。命令会用随包实录和原件重新生成根目录的 `实机演示.html`。

```powershell
python "演示工具/生成演示.py"
```
