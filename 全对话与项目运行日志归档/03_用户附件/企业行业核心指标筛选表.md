# 企业与行业核心指标筛选表

> 筛选标准：
>
> 1. 大部分指标可由年报、季报、交易所公告、国家统计局、海关、人民银行、行业协会或监管报表获得。
> 2. 每个类别只保留最能判断发展状态和趋势的核心指标。
> 3. 不包含估值、DCF、PE、PB、EV 等估值指标。
> 4. 指标异常必须回到业务、会计和行业机制解释，不能单独下结论。

## 一、行业与市场指标

| 指标 | 官方/一手来源 | 能判断什么 |
|---|---|---|
| 行业市场规模及增速 | 国家统计局、行业协会、主管部门 | 行业空间和增长阶段 |
| 行业产量、销量及增速 | 国家统计局、行业协会、主管部门 | 真实需求和生产景气 |
| 产品价格、原材料价格、价差 | 统计局价格指数、行业协会、海关、商品交易所 | 行业景气和利润空间 |
| 产能利用率、行业库存 | 行业协会、主管部门、统计局 | 供需缺口和库存周期 |
| 行业集中度 CR5、CR10、HHI | 行业协会、监管统计、上市公司年报 | 竞争格局和议价权 |
| 进出口量、国产化率 | 海关总署、行业协会、主管部门 | 外部竞争和产业链安全 |
| 政策、监管、技术和标准变化 | 国务院、部委、监管机构和行业协会公告 | 行业结构性变化和失效风险 |

保留原因：这七项可以回答行业“有多大、增长快不快、供需紧不紧、价格好不好、竞争散不散、外部依赖强不强、政策风险大不大”。

## 二、客户与商业模式指标

| 指标 | 官方/一手来源 | 能判断什么 |
|---|---|---|
| 主营业务收入构成和分部增速 | 年报、季报、分部报告 | 收入来自哪些业务，哪块在增长 |
| 前五大客户收入占比 | 年报及附注 | 客户集中度和收入稳定性 |
| 合同负债/营业收入 | 资产负债表、利润表 | 预收款、订单可见度和交付节奏 |
| 应收账款/营业收入 | 资产负债表、利润表 | 客户账期和赊销依赖 |
| 销售费用率 | 利润表 | 获客、渠道和销售效率 |
| 分部毛利率 | 年报、分部报告 | 哪类业务真正赚钱 |

保留原因：这六项可以从公开报表识别“客户依赖、收入结构、预收能力、回款压力、获客成本和业务盈利差异”。

## 三、收入质量指标

| 指标 | 官方/一手来源 | 能判断什么 |
|---|---|---|
| 营业收入同比和三年复合增速 | 年报、季报 | 短期和中期增长 |
| 分部收入增速 | 年报、分部报告 | 增长来自主营业务还是新业务 |
| 销量、价格、产品结构变化 | 年报经营讨论、产销数据、行业协会 | 增长是量、价还是结构驱动 |
| 应收账款及合同资产/收入 | 资产负债表、利润表 | 增长是否依赖赊销或未结算项目 |
| 收现比 | 现金流量表、利润表 | 收入是否真正收到现金 |
| 合同负债/收入 | 资产负债表、利润表 | 未来交付和预收款情况 |

保留原因：这六项能回答“增长是否真实、从哪里来、是否收到钱、未来收入有没有支撑”。

## 四、盈利能力指标

| 指标 | 官方/一手来源 | 能判断什么 |
|---|---|---|
| 毛利率 | 利润表 | 产品定价权、成本和结构 |
| 营业利润率 | 利润表 | 销售、管理和研发效率 |
| 净利率 | 利润表 | 最终盈利水平 |
| 销售费用率、管理费用率、研发费用率 | 利润表 | 费用投入是否有效 |
| 分部毛利率和分部营业利润率 | 年报、分部报告 | 哪块业务贡献利润 |
| 增量营业利润率 | 两期利润表 | 新增收入是否带来高质量利润 |

保留原因：这六项可以形成“毛利率—费用率—营业利润率—净利率—增量利润”的完整盈利链。

## 五、资本效率与增长质量

| 指标 | 官方/一手来源 | 能判断什么 |
|---|---|---|
| ROE | 年报、利润表、资产负债表 | 股东资本回报 |
| ROIC | 利润表、资产负债表 | 经营资本回报 |
| 资产周转率 | 利润表、资产负债表 | 资产使用效率 |
| 增量 ROIC | 两期利润表和资产负债表 | 新增投资是否有效 |
| 资本开支/收入 | 现金流量表、利润表 | 增长需要多少资本 |
| 再投资率 | 现金流量表、资产负债表、利润表 | 增长消耗多少现金 |
| ROE 杜邦分解 | 利润表和资产负债表 | 回报来自利润率、周转还是杠杆 |

保留原因：这七项可以判断“企业赚钱靠什么、增长需不需要大量资本、新增投入是否继续有效”。

## 六、现金与营运资本指标

| 指标 | 官方/一手来源 | 能判断什么 |
|---|---|---|
| 经营现金流/净利润 | 现金流量表、利润表 | 利润含金量 |
| 自由现金流 FCF | 现金流量表 | 可分配现金和再投资能力 |
| 应收账款周转天数 DSO | 资产负债表、利润表 | 客户回款效率 |
| 存货周转天数 DIO | 资产负债表、利润表 | 库存效率 |
| 应付账款周转天数 DPO | 资产负债表、利润表 | 供应商账期和隐性融资 |
| 现金转换周期 CCC | DSO、DIO、DPO | 营运资金占用周期 |
| 净营运资本/收入 | 资产负债表、利润表 | 增长所需的营运资本 |

保留原因：这七项可以回答“利润有没有变成现金、现金被谁占用、增长是否吃现金”。

## 七、资产负债与偿债指标

| 指标 | 官方/一手来源 | 能判断什么 |
|---|---|---|
| 资产负债率和有息负债率 | 资产负债表、附注 | 总体杠杆和融资性债务压力 |
| 净负债/EBITDA | 资产负债表、利润表 | 杠杆和偿债压力 |
| 利息保障倍数 | 利润表、附注 | 利息覆盖能力 |
| 流动比率和速动比率 | 资产负债表 | 短期流动性 |
| 债务到期结构和短期债务占比 | 年报、债券募集说明书、附注 | 再融资压力 |
| 租赁负债、担保和表外义务 | 年报附注、公告 | 隐性债务和风险 |
| 经营现金流/利息 | 现金流量表、利润表 | 现金付息能力 |

保留原因：这七项可以判断“企业借了多少、什么时候到期、有没有现金还、有没有表外压力”。

## 八、会计质量与治理指标

| 指标 | 官方/一手来源 | 能判断什么 |
|---|---|---|
| 应计比率 | 利润表、现金流量表、资产负债表 | 利润的应计程度 |
| 非经常性损益/归母净利润 | 年报、利润表 | 利润是否依赖一次性项目 |
| 研发资本化率 | 年报附注 | 费用资本化是否抬高利润 |
| 商誉/净资产 | 资产负债表、附注 | 并购风险和减值压力 |
| 坏账准备和存货跌价准备 | 年报附注 | 资产计提是否充分 |
| 关联交易、资金占用和担保 | 年报、公告、审计资料 | 治理和利益输送风险 |
| 审计意见、审计师变更和财务重述 | 年报、审计报告、公告 | 财务信息可信度 |

保留原因：这七项可以判断“利润是否真实、资产是否高估、治理是否侵占股东利益”。

## 九、周期、预期与经营校验指标

| 指标 | 官方/一手来源 | 能判断什么 |
|---|---|---|
| 行业库存、产能利用率和价格趋势 | 统计局、行业协会、主管部门 | 行业周期位置 |
| PMI、工业增加值和行业产量 | 国家统计局、行业协会 | 需求和生产的边际变化 |
| 订单、合同负债和交付节奏 | 交易所公告、年报、季报 | 未来收入的可见度 |
| 管理层经营指引与实际完成 | 年报、季报、业绩说明会、公告 | 经营兑现程度 |
| 销量、价格、成本和毛利率趋势 | 年报经营讨论、产销数据、利润表 | 经营变化来自量、价还是成本 |
| 经营现金流与利润趋势 | 现金流量表、利润表 | 经营改善是否有现金支持 |

保留原因：这六项可以判断“行业处在什么位置、公司订单和交付如何、管理层指引是否兑现、经营改善是否真实”。

## 筛选结论

一般企业研究的最小核心指标集合为：

**行业规模与供需、集中度、价格与库存；客户集中度、合同负债、应收和销售费用率；收入增速与量价拆分；毛利率、营业利润率、净利率和费用率；ROE、ROIC、增量 ROIC、资产周转和资本开支；经营现金流/净利润、FCF、DSO、DIO、DPO 和 CCC；净负债/EBITDA、利息保障和债务期限；应计比率、非经常性损益、研发资本化、商誉和审计质量；周期指标、订单和经营指引兑现。**

这组指标数量可控，主要来自官方财报、公告和统计资料，足以判断企业或行业的发展水平、增长质量、盈利质量、现金质量、资本效率、财务安全和周期位置。
