# 天枢 · 全对话归档

**从这里开始**：先看 [运行日志说明](02_运行日志/运行日志说明.md)，再按时间阅读 [对话全文](01_对话/完整对话.md)。如要运行最近的系统，完整解压后双击「当前交付/天枢工作台/START.cmd」。海报采用「当前交付/最终海报-2400x3200.png」。

| 目录 | 内容 |
|---|---|
| 当前交付 | 最后一次系统交付 Tianshu-Sidebar 的运行目录，以及最后确认的大字精简海报 |
| 01_对话 | 本聊天用户消息、助手可见进度与最终回答，含中断记录，按时间排列 |
| 02_运行日志 | 单独的阶段复盘、运行方式、失败与修复、证据说明；CSV 是原会话中可恢复的工具调用时间索引 |
| 03_用户附件 | 原始交付包、团队审查包、指标表、产业链代理要求及可恢复的截图 |
| 04_历代交付包 | 本项目 outputs 中留存的历代发行 ZIP。已弃用的黑夜暖红版只作历史记录 |
| 05_文档报告与海报 | 留存的 README、赛事要求、复核报告、交互 HTML 和各版海报 |
| 06_证据与实跑 | 指标内核前后台账、模型核验快照、PDF 原件与用于定位的文字层等 |
| 07_开发与回归 | 阶段开发与测试脚本、海报脚本和截图素材。部分历史脚本保留当时的工作目录或 Windows 路径；当前系统运行不依赖这些脚本 |

范围为此聊天的可见交流及项目留存成果，截止到归档时。平台内部记录、原始工具指令、其他聊天和浏览器用户目录不随包提供；操作时间线只列可核对的调用元数据。项目里原有的网页链接和来源仍保留，外网可达性取决于使用环境。SHA256SUMS.txt 为本次交付的文件校验值，不含它自身。运行日志说明是基于留存记录整理的复盘，并非完整终端 stdout/stderr 转储。
