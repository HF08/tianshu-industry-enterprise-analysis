# 天枢工作台｜参赛要求与项目架构

命题二「AI 驱动的行业研究与企业经营分析助手」。本项目以中国动力电池行业和宁德时代为主要验证案例，研究企业增长、盈利与现金流变化，以及行业需求和竞争格局如何影响风险判断。

## 赛事要求与对应成果

| 赛事关注点 | 项目实现 | 现场可查的成果 |
|---|---|---|
| 可运行、可演示 | 聚焦一个行业和公开披露企业，以明确研究问题串联流程 | 根目录 START.cmd、演示目录的交互图谱 |
| 多智能体协作 | 天枢识别标的并派单，三个研究角色并行工作，第四个风险角色审查，天枢综合输出 | 主会话、独立角色工作区、正式团队回报 |
| 把企业放进行业中看 | 计算同业候选、观察行业供需与集中度，标注上下游关系 | 样本范围、关系证据、图谱节点详情 |
| 用财务数据解释经营变化 | 从三张报表和年报附注提取数据，按统一公式计算趋势、周转与杠杆指标 | 原始字段、公式字典、五年台账 |
| 核验来源和风险依据 | 标注期间、单位、发布者和页表定位；区分事实 F、计算 C、推断 I、缺失或矛盾 M | 实跑核验目录中的修复前后台账、复核报告与证据原件 |
| 支持追问和更新 | 可直接追问天枢或角色、补录资料、修订范围并重跑 | 带上下文的答复和重派记录。持久化历史和自动监测更新仍待实现 |

赛事要求参赛者选择一个具体行业及一至三家公开资料可查的企业，走通一项研究任务。天枢选用五个完整财年、流式插话及独立角色工作区；这些是本项目的设计选择。产业链图谱是已实现的赛事扩展方向。

## 智能体框架

每个任务由天枢确定研究对象、范围、比较基准与截止日，根据标的启用一组四个子代理。

| 分支 | 并行研究角色 | 下游角色 |
|---|---|---|
| 企业 | FIN 财务计算；BIZ 产品与商业模式；COMP 上下游关联企业及竞争 | RC 企业风险，检查财务异常、经营暴露、反证及待查事项 |
| 行业 | IND 行业状况；CHAIN 上下游分析；DEM 规模客户 | RI 行业风险，检查周期、供需、竞争和政策变化的影响路径 |

一次研究共用一份数据台账。各角色分别接受任务卡、采用自己的系统提示词并调用模型。工作区保留本角色的专业分析、进度和直接对话；交给天枢的是正式简报及研究产物。用户可以选择将某条子代理私聊答复回报天枢。风险代理收到前三个研究角色的结果或失败记录后再审查。资料检索、抽取、核验作为共享工具，天枢负责规划、协调和综合写作。

## 实现架构与接口

| 模块 | 实现位置 | 职责 |
|---|---|---|
| 浏览器工作台与调度 | app/index.html、app/team.js、app/team.css | 会话和角色路由、任务卡、插话、取消重派、状态、定向对话、流式 Markdown |
| 本地 Node.js 服务 | server.mjs、prompts.md | 加载共享契约、角色和风险模式，调用兼容 Chat Completions 的模型服务 |
| 取数与计算 | kernel.mjs、metrics.mjs、disclosures.mjs、source-snapshot.json | 取三表、年报和统计公报；处理来源、口径和期间；计算指标并保留缺项 |
| 角色工具与可视化 | app/role-tools.js、app/chain-map.js | 做产品、同业、产业链、需求与风险分析；按 JSON 渲染图谱和离线导出 |

请求从浏览器进入本地服务。POST /api/models 获取模型列表；POST /api/kernel 返回台账，也可逐行推送取数与计算事件；POST /api/stream 以 SSE 返回模型片段。面向用户的摘要和正文流式展示，供机器消费的 JSON 校验通过后再交接。结构化回报遇到截断或缺字段可自动补试，总计最多三次。

## 口径及验证边界

企业自动取数主要覆盖境内 A 股、人民币合并报表和自然年财务期间。比赛快照主表取 2021—2025 年，近期累计数据另外展示。经营现金流与净利润、集团与分部、期末余额与期间流量分别核对。行业比较先对齐地域、产品、交易环节、金额或实物量；上位行业统计和上市样本集中度须保留样本范围。

例如，协会统计的 2025 年动力电池生产商销量为 1,200.9 GWh，国内装车量为 769.7 GWh。前者包含出口，后者反映国内应用。判断某家企业国内份额变化，还需要它同期间、同口径的国内装车数据。[署名报告及表页见实跑复核](实跑核验/行业与企业取数复核.md)。

真实资料验证覆盖企业与行业取数、程序计算及锂电图谱案例；浏览器与模拟模型回归覆盖角色隔离、定向投递、重试和流式交互。真实模型对自由文本的提取及图谱生成质量仍需按实际配置评估。
