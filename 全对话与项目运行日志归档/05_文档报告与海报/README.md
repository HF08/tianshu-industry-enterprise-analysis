# 天枢 · 行业研究与企业经营分析助手

2026-11-21 比赛交接版，代码基线为「实时对话版」。天枢将一个企业或行业问题拆成四个角色的任务，用程序取数、计算和核对口径，再由模型解释结果。现场演示可从企业或行业任选一个入口；复核结论可直接查看随包台账和证据原件。

## 1. 启动与演示

1. 完整解压 ZIP，保留目录结构。Windows 安装 Node.js 22 或更新版本，双击「天枢工作台/启动工作台.cmd」。也可在该目录运行 `node server.mjs`，打开控制台打印的地址。前端和 Markdown 渲染器已随包提供，无需安装 npm 依赖。
2. 默认服务为 `http://127.0.0.1:18721`。端口被占用时，在 PowerShell 中设置 `$env:TIANSHU_PORT='18722'` 后重新启动。同一个浏览器切换端口会使用另一份本地配置。直接打开应用的 index.html 无法运行取数和模型请求。
3. 点击齿轮或输入框旁的模型名，选服务商、填基础地址与 API Key，获取模型列表或手动输入模型 ID。接口需支持 Chat Completions 的 SSE 流。思考强度“服务默认”省略该参数；兼容接口可选低、中、高，DeepSeek 官方可选低、高、最高。具体模型须支持所选档位。
4. 年报 PDF 自动抽取另需 PATH 中可执行的 `pdftotext`。缺少时，已登记的公告、随包快照及结构化报表仍可使用。联网取数需要相应站点可达；模型调用使用自己配置的账户。配置及 Key 存储在浏览器 localStorage；切勿把浏览器配置目录发给队友。会话和研究过程仅在页面内存中保存，刷新前先下载台账或导出图谱。
5. **企业演示**：输入“分析宁德时代近五年的经营现金流与利润是否一致，核对客户集中度和电池系统产能利用率。”运行中可问“目前哪些年份已经取到？”，结束后追问“38.96%来自哪份年报、分母是什么？”
6. **行业演示**：新会话输入“分析中国动力电池行业，比较销量与国内装车量，展示上游材料、动力电池系统和下游装车的产业链图谱。”离线演示可直接打开 [锂电产业链图谱](演示/锂电产业链图谱.html)。顶栏的“示例报告”展示原型交互，真实本轮结果在主对话、下载台账和本轮生成的图谱中。

## 3. 架构与调用顺序

| 标的 | 第一批派发 | 下游审查 |
|---|---|---|
| 企业 | FIN 财务计算、BIZ 产品与商业模式、COMP 上下游关联企业及竞争 | RC 企业风险 |
| 行业 | IND 行业状况、CHAIN 上下游分析、DEM 规模客户 | RI 行业风险 |

TS 天枢识别标的、确定范围并组队。每轮只有一份 FIN 或 IND 共享台账。三个研究角色并行派发，依赖数据的角色等待同一台账；风险角色等前三份回报或失败记录齐备后审查，最后由天枢汇总。单角色失败显示红点并保留原因。插话由天枢判断是进度/解释请求还是范围变更；前者在原轮次继续，后者中止旧轮并按新要求重派。追问读取当前会话的范围、台账摘要和团队回报。

| 实现位置 | 负责内容 |
|---|---|
| server.mjs、prompts.md | 本地 HTTP 服务；共享契约＋角色正文＋风险模式＋当前动作组装；模型列表与流式代理 |
| kernel.mjs、metrics.mjs | 数据源适配、清洗、期间对齐、冲突检测和公式计算 |
| disclosures.mjs、source-snapshot.json | 公报、巨潮年报及已核验的文档快照；按标的、发布日和统计范围取用 |
| app/role-tools.js | 产品组合、同业筛选、上下游、需求分层和双风险模式的确定性计算 |
| app/team.js、app/index.html、app/team.css | 会话、路由、事件消费、状态栏、Markdown 展示、附件和报告预览 |
| app/chain-map.js | 数据驱动的图谱、节点详情、价值/技术视图、链接降级及单 HTML 导出 |

**接口与事件。** 同源 POST /api/models 按配置读取 /models。POST /api/stream 调用 /chat/completions，服务端透传 SSE；浏览器增量读取 content 并处理跨包标记。plan/work 通过“【摘要】→【数据】”传输；final/answer 通过“【摘要】→【正文】”传输。工作摘要可点击折叠，运行时看末行，结束后看首行；内部 JSON 供代理交接。工作回报要求 summary 为首键，以便长图谱生成完之前展示简报。POST /api/kernel 接受 role、target、as_of、sector、records；默认返回 JSON，Accept: application/x-ndjson 时输出 progress/result/error。模型代理校验 Host/Origin，远程模型地址需 HTTPS，本机回环可用 HTTP。

**证据与交接。** F 为已披露事实，C 为程序计算结果，I 为有依据的推断，M 为缺失、冲突或不可比。任务、快照、证据、计算、结论各有引用；数据台账以 observations → inputs → metrics 追溯，并保留 sources、interim、missing、conflicts、issues。六种研究产物为 CalculationResult、PeerComparison、ChartPosition、IndustryStatus、ChainKeyCompanies、HistoricalComparison，风险另交 RiskFinding。字段要求和缺失处理见[现行契约与各角色提示词](天枢工作台/prompts.md)。提示词约束、程序字段检查和人工核验各有作用；模型返回合法 JSON 仍须核对事实。

## 4. 时间、来源与计算口径

**范围。** 当前自动财务取数面向境内 A 股、人民币合并报表、12 月结账企业。每轮记录 as_of，主表取截止年份之前的五个完整自然年；本次比赛为 2021—2025。历史不足留缺项。同比与期初余额额外读取基年；2021 到 2025 的复合增长有四个间隔，字典的“收入三年复合增速”取 t 与 t−3，使用三个间隔。前三季度累计、单季度、全年、期末余额分别处理。提示词中 TTM 采用“上一全年＋本年前三季度－上年前三季度”，限同口径期间量；现有内核的近期表主要提供三季报观测，并未对所有指标产出 TTM。月度滚动按资料可得期列示，不补零。

**来源。** 财报、公告及附注优先交易所、巨潮和公司原件；行业优先统计局、工信部、海关、监管原表和国家标准平台，再采用署名协会及研究机构自有调查。东方财富财报属于转录；WDI、乘联分会和 UN Comtrade 各保留原统计定义。券商研报区分自有调查、第三方转引、推断及预测。记录发布者、资料版本、期间、发布时间、取数时间、单位、原文页/表或章节。当前数据库可能已修订，有些接口只有查询时现值，历史截止日无法保证还原旧版。文件快照与实时接口的覆盖范围见[接口说明](天枢工作台/指标接口说明.md)。

**数据一致性。** 金额归一为人民币元，万元/亿元显式换算；比率区分百分数、百分点和倍数。同一年度、字段与业务维度存在不同数值或单位时列冲突。零分母、不可用基数、关键字段缺失等按公式留空；不将“未披露”当成零。同业候选按同分类、营业总收入与标的的对数规模距离筛选，须再核对产品、地域和分部；护城河需至少两类证据互证。风险级别与证据置信度分别记录，不输出买卖建议、目标价或自动授信结论。

| 指标组 | 执行口径与容易混淆的地方 |
|---|---|
| 财务及盈利 | 毛利率=(收入−对应成本)/收入；净利率取合并净利润，归母利润另列。资产负债率=期末总负债/期末总资产。产品占比用分部收入与集团收入，分部同比需同名同定义 |
| 资本效率 | ROE 为归母利润/平均归母权益；杜邦使用归母净利率、资产周转、归母权益乘数。ROIC 用税后经营利润/平均投入资本，投入资本代理为净资产＋有息负债−现金等价物。增量 ROIC 用两期差额，投入资本未增加时留缺 |
| 现金、周转、偿债 | FCF 为经营净现金−资本开支；DSO、DIO、DPO 用期初期末平均余额与实际年度天数。DSO 用收入，DIO 与 DPO 用营业成本，CCC=DSO+DIO−DPO。速动口径扣存货。到期合同现金流、经营性应付与有息借款区分 |
| 会计及治理 | 非经常损益、研发资本化、应计比率、商誉及减值依附注。区分计提额与期末余额、批准担保额度与实际担保余额、集团与母公司；客户匿名时保留原称谓。银行/保险改用专用指标 |
| 行业供需、竞争 | 区分市场销售额、产值、增加值、生产商销量、终端装车和出口净重。CR5/CR10 按同口径份额排序求和；HHI 采用0—10000刻度。上市样本合并收入集中度仅代表该样本 |
| 价值链与客户 | 不把意向、定点、资格认定等同已实现交易；TAM 与可及市场分列。分子分母须同范围、期间和单位。利用率取实际产出/有效产能；量价拆解要求产品、币种、单位及收入确认口径可比 |

**完整公式附录随包提供。** [指标字段字典](天枢工作台/指标字段字典.json)列出企业通用、行业通用、制造、零售消费、SaaS/互联网、银行、保险、地产工程、公用事业和医药生物模板的公式、单位、输入和披露项；[公式实现](天枢工作台/metrics.mjs)另含通用校验与集中度计算。[原始指标筛选表](原始资料/企业行业核心指标筛选表.md)保存需求口径，具体某项能否计算由当轮输入决定。

## 5. 资料补录与图谱

输入框“＋”接收结构化观测数组或带元数据和原文的 JSON 研报包。标的须匹配派单名称；原文匹配按数值、单位、期间与定位核验，抽取失败仍继续公开接口取数。完整字段、样例和 PDF 限制见[补录说明](天枢工作台/指标接口说明.md)。研究者应核对发布者身份及统计方法；文本匹配本身不能证明来源真实。

企业 COMP 与行业 CHAIN 返回 chainGraph，图谱在完整 JSON 可解析后挂载到对话。stages/supports/nodes 定义主链与配套，valueView/techView 可选。节点支持指标、企业及来源链接；仅在有同口径数据时展示成本条和毛利率区间。折叠交互、键盘操作、窄屏布局及受限 iframe 链接降级由组件负责。案例价值分布为宁德时代企业样本，技术路线使用同一季度国内装车数据。

## 6. 已验证结果、复现与边界

- 实际来源核验采用 2026-11-21 北京时间16:00的快照，真实运行 FIN/IND 与六个角色程序计算。行业年度结果17→54条，企业273→312条；计数包含年度、指标、范围组合，不是独立指标数。动力电池2025年销量1200.9 GWh，国内装车769.7 GWh。HS850760净重覆盖多用途蓄电池。宁德时代前五客户占比2021—2025年分别为31.32%、35.33%、36.78%、37.03%、38.96%。上述数字的来源、核验差异和限制见[实跑复核](实跑核验/行业与企业取数复核.md)。
- 从包根目录运行 `node 工具/verify-stream.mjs`。回归使用模拟流式模型和真实浏览器，本机须有 Chrome、可用网络和空闲调试端口19349。可用环境变量 CHROME_PATH 指向浏览器。测试覆盖路由、插话、公开摘要首末行、流式 Markdown、失败卡片、研报候选、图谱与会话隔离。真实模型自由文本抽取和图谱生成质量仍需用实际账户评估。
- 运行 `node 工具/generate-graph.mjs` 可由随包台账和原件文字层重建演示；`node 工具/build-source-snapshot.mjs` 重建已核对的来源快照。后者复用人工定位记录与 PDF 指纹。若发布者修订文件，应重新核对页码、表列及数值。
- 接口限流、PDF错列或字段缺失时查看台账 issues、missing、conflicts，再按来源补录。细分行业完整销售额、库存、全口径有息负债等仍可能缺失。历史会话持久化、任意行业的全覆盖抓取和实时行情均不属于当前已验证能力。
